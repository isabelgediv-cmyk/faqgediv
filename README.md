# Central de Orientações da GEDIV

A Central de Orientações da Gerência Executiva de Concessão de Direitos e Vantagens (GEDIV), vinculada à Secretaria de Estado da Administração da Paraíba (SEAD-PB), reúne perguntas e respostas para facilitar o acesso a informações sobre os assuntos de competência da Gerência.

## Objetivos

- Facilitar o acesso às orientações.
- Padronizar as informações disponibilizadas.
- Apoiar o atendimento aos servidores públicos estaduais.

## Acesso

**Site:** https://centralgestaopublica.com.br

## Tecnologias

HTML, CSS, JavaScript e GitHub Pages.

## Observação

O conteúdo possui caráter consultivo e orientativo. As informações devem ser consideradas conforme a legislação aplicável e as particularidades de cada caso, não substituindo a análise administrativa dos processos.
